## 一、这是什么？

**一句话**：一个以“我的记忆”为中心、而不是以“官方 POI”为中心的私人地图日志 App。

**核心动作**：

- 到了某个地方 → 用 GPS 一键落点，或在地图上手动戳点/拖动微调

- 写下文字、拍照、打标签、记录时间

- 之后能在地图上看到钉子、按时间线翻看、搜索

**技术约束**：

- Android 12+（minSdk 31）

- 本地优先，未来同步/分享

- 离线可用

- 导航靠跳转高德/其他 App

## MVP 边界（第一版做什么、不做什么）

**做：**

1. 地图页：显示所有钉子 + 当前定位 + 精度圈

2. 落点两种方式：GPS 一键 / 手动戳点+拖动

3. 记录编辑：文字、照片（1~多张）、标签、时间戳

4. 时间线列表页

5. 搜索（先做标题+文字+标签的本地模糊搜索）

6. 点钉子 → 查看详情 → 跳转高德导航

7. 本地持久化 + 无网可记录

**暂时不做（但要留接口）：**

- 云同步、账号、分享

- 完整离线地图包

- App 内导航

- 社交、评论、公开地图

- 复杂标签体系（先做扁平标签，不做层级）





## 页面结构草案

├── 地图页（首页）
│   ├── 全屏地图 + 钉子
│   ├── 悬浮按钮：定位到我的位置
│   ├── 悬浮按钮：在此落点（长按地图也可）
│   └── 底部抽屉：附近记录 / 快速入口
│
├── 时间线页
│   └── 按时间倒序的记录卡片
│
├── 搜索页（搜索框悬浮在首页正上方）
│   └── 输入框 + 结果列表（点结果回到地图定位）
│
├── 记录详情页
│   ├── 照片、文字、标签、时间、坐标、精度
│   ├── 编辑 / 删除
│   └── 按钮：跳转高德导航
│
└── 记录编辑页（新建/修改）
    ├── 地图小窗 + 可拖动钉子
    ├── 经纬度 / 精度显示
    ├── 文字输入
    ├── 照片选择
    └── 标签输入
